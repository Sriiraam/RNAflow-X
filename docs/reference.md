# Reference Specification

## 1. Reference Strategy

RNAflow-X uses a transcriptome-based reference rather than the complete GRCh38 genome.

This design was selected to reduce storage, indexing time and memory requirements while retaining a biologically appropriate reference for transcript quantification.

## 2. Genome Assembly

**GRCh38.p14**

## 3. Annotation Release

**GENCODE v50**
